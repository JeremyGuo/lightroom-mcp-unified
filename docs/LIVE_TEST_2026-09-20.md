## 本次修复并复测的问题

1. **导入忽略复制目录**：公共 schema 使用 `copy_to`，Lua 却只读取 `destination`。Lua 现在优先读取 `copy_to`，保留旧 TCP 参数别名；回归测试改用公共参数名。
2. **立即预览仍是旧图**：控制器已读回新滑块值，但目录尚未保存。原版本相邻两次 JPEG 的解码像素完全相同；稍后预览才变化。现在结束 tracking，并等待能映射到目录数值字段的修改读回一致，再返回成功；超时会报告失败。此修复不声称等待所有 AI 或局部蒙版计算完成。参照 [Adobe SDK 的 stopTracking 说明镜像](https://lrc.mcor.dev/modules/LrDevelopController.html#LrDevelopController.stopTracking)。
3. **新导出目录失败**：Lightroom 不会自动创建目标目录。现在导出前创建目录，并在失败时提供明确错误；已重新导出三种格式验证。

## 尚未通过 / 尚未验证

- **热重载连接残留**：在插件运行中点击“重新载入增效工具”，曾出现端口可连接但无响应，随后日志出现 token mismatch。完整退出 Lightroom，重新启动并在增效工具管理器启动服务后恢复。尚未修复根因；升级时先停止服务，必要时完整重启 Lightroom。
- **启动时自动加载**：本轮重启后服务没有立即监听；打开增效工具管理器并启动后正常。不能宣称自动启动已通过。
- **Lens Blur**：`lr_lens_blur(active=false)` 在当前 JPEG 上返回 `LensBlurActive` 回读不匹配。尚未修复或确认具体原因；不计为通过。
- **Auto Tone / Reset 的异步状态**：连续调用 `lr_auto_tone`、`lr_reset` 后立即应用 Exposure/Contrast，出现“Slider unavailable for this image: Contrast”。前两项返回成功，但重置效果和后续就绪时机没有可靠完成确认，因此不计为完整验收。
- **RAW 与 AI Enhance**：JPEG 正确拒绝 denoise；未执行真实 NEF/DNG 降噪、Raw Details、Super Resolution，未验证 RAW/JPEG 混合白平衡批处理。
- 未覆盖 Windows、长时间空闲、数百张照片、磁盘满、所有导出冲突模式、全部蒙版类型和全部参数组合。
